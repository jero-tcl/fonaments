# Reunió de famílies · 2n Batxillerat Artístic · 2026/27

Presentació HTML preparada per a GitHub Pages.

## Fitxers
- `index.html` — presentació.
- `assets/logo-ondara.png` — logo de l'Escola d'Art Ondara.
- `assets/calendari-ondara-2026-27.pdf` — calendari complet del centre.

## Publicar a GitHub Pages
1. Puja aquests fitxers mantenint l'estructura de carpetes.
2. A GitHub: **Settings → Pages**.
3. Selecciona **Deploy from a branch**, la branca (normalment `main`) i la carpeta `/ (root)`.
4. Desa i obre l'adreça que GitHub Pages indiqui.

## Controls
- `→`, `Espai` o `Page Down`: següent.
- `←` o `Page Up`: anterior.
- `Home`: portada.
- `End`: final.
- També hi ha els botons de navegació a la pantalla.

La presentació no necessita connexió externa per funcionar: el logo i el PDF del calendari són locals.
